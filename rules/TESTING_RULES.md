# Требования
- Все классы, содержащие бизнес-логику, должны иметь соответствующие unit-тесты
- Тесты должны покрывать как минимум 80% кода классов с бизнес-логикой
- Каждый публичный метод класса с бизнес-логикой должен быть протестирован
- Все тесты должны проходить успешно, после изменений
- Для каждого нового класса с бизнес-логикой должен быть создан соответствующий тестовый класс с суффиксом Test
- Убедиться, что все тесты проходят
