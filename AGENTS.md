# Agents.md

## 🎯 Цель проекта
Разработка REST API сервиса на Java Spring Boot с использованием PostgreSQL.  
Проект следует многослойной архитектуре (Controller → Service → Repository), чистоте кода, принципам REST и best practices Spring Boot.

## 🧠 Стек технологий
- **Java 22+**
- **Spring Boot**
- **Spring Data JPA / Hibernate**
- **PostgreSQL** (основная БД)
- **Liquibase / Flyway** (миграции)
- **Maven**
- **Lombok** (для сокращения бойлерплейта)

## workflow
- Проанализировать задачу
- Определить классы для изменения или создания
- Создать список задач для выполнения
- Внести изменения в проекте(используя skills)
- Создать или исправить unit-test
- Запустить unit-test(если тесты провалились, исправить их и перезапустить, пока все тесты не будут корректно выполнены). Правила описаны в rules/TESTING_RULES.md
